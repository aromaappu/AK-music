# AK music

Advanced YouTube Music client for Android, built with Material Design 3.

## Features

- Ad-free playback
- Background playback with lockscreen and notification controls
- Downloads and offline playlists
- Last.fm / ListenBrainz scrobbling
- Discord Rich Presence
- Music Together sessions
- Lyrics, equalizer, and audio settings
- Android 6.0+ (API 23+)

## Build

Requires JDK 21 and the Android SDK.

```
./gradlew assembleUniversalDebug
```

To build a release APK:

```
./gradlew assembleUniversalRelease
```
